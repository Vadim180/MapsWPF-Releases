# MapsWPF

Репозиторій готових інсталяторів та оновлень MapsWPF для Windows x64.

Вихідний код застосунку тут не публікується. Архіви Source code, які GitHub додає автоматично, містять лише файли цього репозиторію, а не проєкт програми.

## Стан випуску

Перший публічний реліз ще не опубліковано. Інсталятори з’являться в розділі Releases після завершення перевірок і підготовки до розповсюдження.

## Встановлення

Після публікації релізу завантажуйте його інсталятор — файл із закінченням `-Setup.exe` — у розділі Releases. Після встановлення програма пропонує доступні оновлення та показує прогрес завантаження. Перезапуск виконується за згодою користувача після збереження роботи.

Залежно від відмінностей між версіями завантажується delta-пакет або повний пакет. Без інтернету встановлена програма продовжує працювати.

Оновлення випускаються окремо від розробки: нова версія стає доступною користувачам лише після публікації релізу. Звичайне збереження коду та коміти не запускають публікацію.

## Дані

Особисті налаштування та статистика не входять до інсталятора. Не додавайте до публічних звернень свої журнали, статистику, координати чи ключі API.

Ліцензійні умови залежностей додаються до дистрибутива окремо. Публічний доступ до інсталятора сам по собі не надає ліцензію на вихідний код застосунку.
